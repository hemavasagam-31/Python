# Operators

## Simple Explanation

Operators perform operations like arithmetic, comparison, and logical checks.

## Folder Contents

- `examples.py` - Basic examples for this topic
- `exercises.py` - Practice prompts for you to solve
- `solutions.py` - Sample solutions for the exercises and practice problems

## Beginner Exercises

2. Check if first number is less than second number.

## Practice Problems
