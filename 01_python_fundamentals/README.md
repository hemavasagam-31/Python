# Python Fundamentals

## Simple Explanation

Python is a programming language used to write instructions for computers.

## Folder Contents

- `examples.py` - Basic examples for this topic
- `exercises.py` - Practice prompts for you to solve
- `solutions.py` - Sample solutions for the exercises and practice problems

## Beginner Exercises

1. Print your name.
2. Print the result of 10 - 4.
3. Create a variable age and print it.

## Practice Problems

1. Write a program to print three favorite hobbies line by line.
2. Calculate and print the area of a rectangle (length 6, width 4).
