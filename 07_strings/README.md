# Strings

## Simple Explanation

Strings are text values. You can slice, format, and transform them.

## Folder Contents

- `examples.py` - Basic examples for this topic
- `exercises.py` - Practice prompts for you to solve
- `solutions.py` - Sample solutions for the exercises and practice problems

## Beginner Exercises

1. Create a string message and print it in uppercase.
2. Print first and last character of a word.

## Practice Problems

1. Count vowels in a word using a loop.
2. Reverse a string using slicing.
