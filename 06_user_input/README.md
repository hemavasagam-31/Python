# User Input

## Simple Explanation

Use input() to accept data from the keyboard as text.

## Folder Contents

- `examples.py` - Basic examples for this topic
- `exercises.py` - Practice prompts for you to solve
- `solutions.py` - Sample solutions for the exercises and practice problems

## Beginner Exercises

1. Ask user for favorite color and print it.
2. Ask user for two numbers and print their sum.

## Practice Problems

1. Ask for temperature in Celsius, convert to Fahrenheit.
