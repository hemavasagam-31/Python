# Loops

## Simple Explanation

Loops repeat actions. Use for-loops for sequences and while-loops for conditions.

## Folder Contents

- `examples.py` - Basic examples for this topic
- `exercises.py` - Practice prompts for you to solve
- `solutions.py` - Sample solutions for the exercises and practice problems

## Beginner Exercises

1. Print numbers 1 to 10 using a loop.
2. Print multiplication table of 5.

## Practice Problems

1. Find sum of numbers from 1 to 100.
2. Count how many even numbers in a list.
