# Python Learning Journey 🐍

Welcome! This repository is a beginner-friendly path to learn Python from basics to advanced concepts through **explanations, examples, exercises, practice problems, and mini-projects**.

## Learning Roadmap

Follow topics in order:

1. `01_python_fundamentals`
2. `02_variables`
3. `03_data_types`
4. `04_type_conversion`
5. `05_operators`
6. `06_user_input`
7. `07_strings`
8. `08_conditional_statements`
9. `09_loops`
10. `10_functions`
11. `11_lists`
12. `12_tuples`
13. `13_sets`
14. `14_dictionaries`
15. `15_oop`
16. `16_mini_projects`

## How to Use This Repository

Each topic folder contains:

- `README.md` → simple concept explanation
- `examples.py` → beginner-friendly runnable examples
- `exercises.py` → coding tasks for practice
- `solutions.py` → one possible set of solutions

### Suggested Study Method

1. Read the topic `README.md`
2. Run `examples.py`
3. Solve tasks in `exercises.py`
4. Compare with `solutions.py`
5. Move to the next folder

## Run Python Files

```bash
python path/to/file.py
```

Example:

```bash
python 10_functions/examples.py
```

## Mini-Projects

The `16_mini_projects` folder includes hands-on practice projects to combine what you learned.

## Goal

By the end of this journey, you should be comfortable writing Python programs, solving problems, and building small applications with confidence. 🚀
