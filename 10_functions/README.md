# Functions

## Simple Explanation

Functions group reusable code blocks and can accept inputs.

## Folder Contents

- `examples.py` - Basic examples for this topic
- `exercises.py` - Practice prompts for you to solve
- `solutions.py` - Sample solutions for the exercises and practice problems

## Beginner Exercises

1. Write a function square(n) that returns n*n.
2. Write a function is_even(n) that returns True/False.

## Practice Problems

1. Write a function to find the largest of three numbers.
2. Write a function count_words(sentence).
