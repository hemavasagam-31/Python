# Data Types

## Simple Explanation

Common data types include int, float, str, bool, list, tuple, set, and dict.

## Folder Contents

- `examples.py` - Basic examples for this topic
- `exercises.py` - Practice prompts for you to solve
- `solutions.py` - Sample solutions for the exercises and practice problems

## Beginner Exercises

1. Create one variable for each: int, float, str, bool.
2. Print the type of each variable.

## Practice Problems

1. Store 5 fruits in a list and print the second fruit.
2. Create a dictionary with keys name and grade.
